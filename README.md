# Job Tracker

A production-minded job application tracker built with Java 21 and Spring Boot.

## Prerequisites

- JDK 21
- Git

The project includes the Maven Wrapper, so a separate Maven installation is not required.

## Build and test

Run `./mvnw clean verify`.

## Run locally

Run `./mvnw spring-boot:run`.

The application starts at http://localhost:8080.

REST endpoints will be added incrementally as the project develops.
